# ReelGauge

Battery-optimized Android Instagram Reel counter with a top-center floating progress pill, persistent daily usage notification, customizable daily limits, and 7-day streak insights.

## One-Click Download APK

- **[Download ReelGauge.apk](apk/ReelGauge.apk)** *(pre-built APK committed directly in this repository — tap "View raw" on GitHub to download immediately)*
- Automated builds are also published to **Releases** on push via GitHub Actions.

## Local Build

```bash
gradle :app:publishApkToRepo
```
